# Video Assistant for AI Training Data

Инструмент для автоматизации первичного поиска и фильтрации видеоконтента для обучения AI-моделей.

## Возможности
- Автоматический сбор ссылок с YouTube по ключевым словам.
- Техническая фильтрация (например, по длительности видео).
- Экспорт результатов в CSV-таблицу для удобного импорта в систему.

## Установка и запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите программу:
   ```bash
   python main.py
   ```

## Как это работает
Программа использует библиотеку `yt-dlp` для получения метаданных видео без их скачивания, что позволяет обрабатывать сотни ссылок за несколько секунд.
